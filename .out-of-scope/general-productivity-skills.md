# General productivity skills

**What was asked:** skills that are useful to a developer but are not a step in the spec pipeline, such as commit message writers, code explainers or refactoring helpers.

**Why it is out:** every skill here is a step in the pipeline or the reference for its order. A skill outside the pipeline would add to every install without closing a gap in the pipeline.

**What to use instead:** install a skill collection made for that job beside these skills. A planned pipeline skill, such as those listed in `SCOPE.md`, is in scope.
