# An IDE or editor extension

**What was asked:** an extension for an IDE or editor that runs the pipeline or shows the work item documents.

**Why it is out:** the skills are plain Markdown that any agent reading skills can load, and every document they write is a file in the repository. An extension would tie the pipeline to one editor and need its own release and support for each one.

**What to use instead:** install the skills for your coding agent, as the README describes, and open the files in `project/work-items/` in any editor.
