# A hosted service

**What was asked:** a hosted service that runs the pipeline, stores the work items or shows the gate results.

**Why it is out:** the audit trail stays in the repository, next to the code it describes, and goes through the same review as the code. A hosted copy would split that record and add an account, storage and uptime to maintain.

**What to use instead:** commit the work item files, and review them in the pull request with the code.
