# AGENTS.md

A small text statistics library in Python, standard library only.

## Commands

- Build: `python3 -m compileall -q textstats`
- Test: `python3 -m unittest discover -s tests -t .`

## Conventions

- Code lives in the `textstats/` package and tests in `tests/`, one test module per code module.
- Commit messages: `feat(spec-NN): task N <title>`.
