# Glossary: Billing

Terms of the Billing context.

## Terms

### Billing_Period

One calendar month in UTC. Usage resets at the start of each Billing_Period.

- **Status:** agreed
- **Since:** import

### Invoice

The amount an Account owes for one Billing_Period, issued on the first day of the next one.

- **Avoid:** Bill, Statement
- **Status:** agreed
- **Since:** import
